# qType — Database Schema

Three tiers. Each tier is populated by a different pipeline stage and can be reset/rebuilt without touching the tier above it.

```
Tier 1 — Raw            (immutable, 1:1 with source JSON)
  qsource ──────────────┐
  qentry ───────┐       │
  qheadword     │       │
                ▼       ▼
Tier 2 — Parsed         (lemma graph, derived from Tier 1)
  qlemma
  qlemmaentry (m:n qlemma ↔ qentry)
  qdefinition
  qetymology
  qexample
  qphrase

Tier 3 — Derived        (morphology + corpus stats, derived from Tier 2)
  qwordform
  qfrequency
  qmisspelling

qpipelinerun            (audit trail for stage runs)
```

## Tier 1 — Raw

### qsource
`id, title, addTime, qStatus` — mirrors `sq_source.json`. Primary key is the original sid so `qentry.sourceId` is stable across re-runs.

### qentry
| Column | Notes |
|---|---|
| `id` | auto increment |
| `rawIndex` | unique; position in `sq_items.json`. Resume key. |
| `rawHeadword` | original `sq_word` string (may contain commas) |
| `rawHtml` | original `sq_text` HTML, untouched |
| `sourceId` | FK → qsource.id |
| `entryDate` | parsed `sq_date` (nullable) |

### qheadword
Headwords split from variant lists (`"ЖАЙ, ЖӘЙ"` → 2 rows, `variantIndex` 0/1).

| Column | Notes |
|---|---|
| `entryId` | FK → qentry.id |
| `text` | single variant (trimmed, original case) |
| `textNormalized` | lowercased, whitespace-collapsed; primary lookup key |
| `variantIndex` | 0-based position within the entry's variant list |
| `isPhrase` | 1 if the headword contains a space |
| `isDialectal` | 1 if the entry text starts with a dialectal marker like `(Жамб.: Қорд., Шу)` |

Indexes: `textNormalized` (B-tree), `entryId`, `(isPhrase, qStatus)`, FULLTEXT on `text`.

## Tier 2 — Parsed

### qlemma
Canonical base forms. One row per word, regardless of how many dictionaries describe it.

| Column | Notes |
|---|---|
| `text` | UNIQUE; lowercase canonical form |
| `pos` | `noun`, `verb`, `adj`, … (filled when morphology runs) |
| `isPhrase`, `isDialectal`, `isLoanword` | flags |
| `latinTranslit` | derived via Cyrl2Latyn (lookup helper available in COMMON layer of the .NET template) |

### qlemmaentry
M:N link `(lemmaId, entryId)` — one lemma is documented by many raw entries; one entry may describe multiple lemmas.

### qdefinition, qetymology, qexample, qphrase
Parsed payloads extracted from `qentry.rawHtml` by Stage 3. Each row carries `entryId` + `sourceId` for provenance.

## Tier 3 — Derived

### qwordform
Inflected forms generated by the morphology service (apertium-kaz by default). UNIQUE `(lemmaId, form)`. `features` is a JSON blob like `{"case":"abl","number":"sg","person":"1"}`.

### qfrequency
Per-form corpus counts. Composite PK `(form, source)` so multiple corpora (`web`, `news`, `books`) can coexist.

### qmisspelling
Hand-curated and learned typo → lemma mappings. `origin` distinguishes (`manual` vs `learned`).

## Conventions

- Charset: `utf8mb4`, collation `utf8mb4_0900_ai_ci`
- Engine: InnoDB
- Names: lowercase, no separators (`qheadword`, not `q_headword`); columns camelCase
- Standard audit fields: `addTime`, `updateTime` (Unix seconds), `qStatus` (0=ok, others = stage-specific)
- No FK constraints in DDL (matches the rest of the Atasuai stack) — referential integrity is enforced in the .NET layer
